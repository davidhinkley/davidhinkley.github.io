⚡ How it works

  • Open a course page — first load fetches the Python engine (~10 MB) once, then it works offline.
  • Press ▶ Run on any box; edit fearlessly with Ctrl+Enter to run. Your edits and checkmarks auto-save in the browser.
  • input() appears as a dialog; files live in a sandboxed in-browser filesystem.
  • Progress bars, per-lesson checkmarks, quizzes with explanations, and a built-in console (>_) sharing state with every lesson.
💚 Beginner-friendlyRead a little, run a lot. Wrong predictions teach the most — every lesson asks you to guess first.
🔒 PrivateNo account, no telemetry, no server. Code runs locally via Pyodide (CPython → WebAssembly).
🧰 Goes furtherFoundations Lesson 8.4 and Intermediate Module 6 coach you onto your own computer: editors, pip/venv, pytest.
